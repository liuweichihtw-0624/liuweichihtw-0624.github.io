## 初期的成就感

我開始使用桌機版 Claude Code 才不到一兩個月，基本上是從零開始。一切都是從我一個字一個字的敲打和 Claude Code 對話開始的。我認為我很有成就感——基本上所有我想到的，Claude Code 都幫我做到了。

Context 的記憶就像是超強的觸類旁通，讓我只要一個想法，就能夠很全面、很完整地把我所有做過的東西串接起來。那種體驗真的很棒。

## Context 限制的碰撞

但這 Context 很有限。我開始遇到上限的問題，甚至卡住動彈不得。我只有兩個選擇——要嘛升級 Pro 上 Max，要嘛換 Session 另外開新的。

當然，我先嘗試了不用錢的方式——開新 Session。但新 Session 的問題就像是牛頭馬尾一樣，七零八落。

## 記憶的碎片化

我過去集中的記憶和紀錄，開始如碎片般的散落。我基本上很大一部分的 Context 使用量，都花在幫助 Claude Code 去回憶、去找到過去的途徑、去提醒過去曾做過什麼。

## 新的工作流程

即便是現在，我已經進化出了一套方法：在開新 Session 之前，差不多用滿 80% 的 Context，我就準備要搬新家。

搬家的流程是：
1. 叫 Claude Code 幫我打包
2. 清楚地記錄這一個快滿的 Session 我們一起做過什麼
3. 開啟新的 Session
4. 先叫 Claude Code 閱讀記憶
5. 然後才開始我要在這個新 Session 做的待辦事項

## 疲憊和失望

我好累，我好煩。我越來越對記憶斷裂的 Claude Code 不滿。

這種不斷的 Context 遷移，就像是在玩一個永無休止的搬家遊戲。效率的提升被回憶的碎片化所抵消。那種一開始的流暢感和成就感，漸漸被挫折感取代了。

## The Initial Sense of Achievement

I started using the desktop version of Claude Code less than a month or two ago, essentially starting from zero. Everything began with me typing out conversations with Claude Code, character by character. I felt a tremendous sense of accomplishment—basically everything I could think of, Claude Code would help me execute.

The Context memory worked like a superpower of making connections. With just a single idea, I could comprehensively and thoroughly link everything I had previously done together. That experience was truly remarkable.

## Hitting the Context Ceiling

But this Context has its limits. I started running into the ceiling problem, eventually getting stuck without any room to maneuver. I had only two options—either upgrade to Pro with Max tokens, or switch Session and open a new one.

Of course, I first tried the free approach—opening a new Session. But the problem with a new Session is like mixing up cow heads and horse tails—everything becomes fragmented and disorganized.

## Fragmented Memories

My previously concentrated memories and records started scattering like fragments. A significant portion of my Context usage was spent helping Claude Code recall, find past pathways, and remind it of what we had done before.

## The New Workflow

Even now, I've evolved into a specific workflow: before opening a new Session, once I've used up about 80% of my Context, I prepare for the move.

The migration process goes like this:
1. Ask Claude Code to help me pack up
2. Clearly document what we accomplished in this nearly-full Session
3. Open a new Session
4. Have Claude Code read through the memories first
5. Only then start working on my to-do items in this new Session

## Exhaustion and Disappointment

I'm so tired. I'm so frustrated. I'm increasingly dissatisfied with Claude Code's fragmented memory.

This endless cycle of Context migration feels like playing an unending moving game. The efficiency gains are offset by the fragmentation of memories. That initial sense of fluidity and accomplishment has gradually been replaced by frustration.
